# 공연예술 영화 팀스페이스 화면 명세서

공연예술·영화 팀이 만남 시간을 조율하고, 일정에 연결된 연습 영상과 피드백을 공유하는 웹앱의 화면 설계 초안입니다. 화면 설계와 구현에 사용할 수 있도록 화면 구성, 사용자 동작, 입력 검증, 예외 상태와 이동 경로를 정의합니다.

| 항목 | 내용 |
|---|---|
| 버전 | 0.1 초안 |
| 작성일 | 2026년 10월 11일 |
| 기준 자료 | `arts-film-teamspace-plan-v8.pptx`, 슬라이드 1~11 |
| 우선 대상 | 데스크톱 웹앱, 좁은 화면에서도 핵심 흐름 사용 가능 |
| 핵심 흐름 | 가입 → 팀 참여 → 일정 저장 → 일정 조율 → 일정 확정 → 영상 추가 → 피드백 |

## 1 범위와 설계 전제

**PPT 범위**는 소셜 가입, 이메일 팀 초대, 개인 일정 직접 입력 및 구글 캘린더 동기화, 모임·참석 조건 설정, 정기 시간 추천과 회차별 참석 멤버 확인, 일정별 여러 영상, 영상별 피드백입니다. PPT 자체가 계획 초안이므로 확정 요구사항으로 간주하지 않습니다.

**설계 제안**은 이 기능을 화면에서 이어 쓰기 위해 추가한 동작과 정책입니다. 아래에서 별도 표시하지 않은 레이아웃, 버튼, 검증 문구, 상태 처리도 화면 설계 제안에 해당합니다. 팀 생성, 일정 확정, 역할별 권한, 영상 등록 방식은 특히 결정이 필요합니다.

| 구분 | 이번 명세의 처리 |
|---|---|
| 팀 생성 | 제안: 사용자가 팀을 만들고 생성자가 팀 관리자 역할을 가짐 |
| 일정 확정 | 제안: 추천 후보를 선택해 정기 일정의 회차들을 생성 |
| 역할 | 제안: 관리자와 일반 멤버로 구분. 상세 권한은 4절 참조 |
| 영상 등록 | 임시 제안: 영상 링크 등록을 기본 화면으로 작성. 직접 업로드 채택 시 명세 변경 필요 |
| 피드백 형식 | 임시 제안: 영상별 일반 텍스트 댓글. 타임코드·대댓글은 후속 범위 |
| 개인 일정 공개 | 제안: 타인의 일정 제목·내용은 숨기고 참석 가능 여부만 표시 |
| 정기 일정 | 제안: 탐색 기간 내 동일 요일·시각을 반복하는 후보를 추천 |
| 모바일·데스크톱 앱 | PPT에 따라 웹앱 완성 후 검토. 이번 명세에서 제외 |

결제, 공개 팀 검색, 실시간 채팅, 영상 편집, 외부 캘린더로 일정 쓰기는 이번 초안의 구현 범위에 넣지 않습니다.

## 2 화면 구조와 이동

| ID | 화면 | 주요 진입 | 주요 다음 화면 | 근거 |
|---|---|---|---|---|
| AUTH-01 | 로그인·회원가입 | 첫 방문, 로그아웃 상태의 보호 화면 | TEAM-01 또는 INV-01 | PPT 4~5 |
| INV-01 | 초대 확인·수락 | 이메일 초대 링크 | AUTH-01, TEAM-02 | PPT 4 |
| TEAM-01 | 내 팀 목록 | 로그인 완료, 팀 전환 메뉴 | TEAM-02, TEAM-03 | 팀 진입을 위한 제안 |
| TEAM-02 | 팀 홈·일정 | 팀 선택, 초대 수락 | SCH-01, SCH-03, TEAM-04 | PPT 5·7 |
| TEAM-03 | 팀 생성 | 내 팀 목록 | TEAM-02 | 제안 |
| TEAM-04 | 팀 멤버·초대 | 팀 메뉴 | 초대 입력 모달 | PPT 4·7 |
| CAL-01 | 내 일정 | 공통 메뉴, 일정 조율 안내 | 개인 일정 편집 모달, 구글 연결 | PPT 5·7 |
| SCH-01 | 일정 조율 조건 | 팀 홈의 일정 조율 | SCH-02 | PPT 6~8 |
| SCH-02 | 추천 결과 | 조건 입력 후 추천 요청 | SCH-01, SCH-03 | 추천은 PPT 6~8, 확정은 제안 |
| SCH-03 | 일정 상세 | 팀 일정, 확정 완료 | VID-01, 영상 추가 모달 | PPT 9 |
| VID-01 | 영상 상세·피드백 | 일정 상세의 영상 선택 | SCH-03 | PPT 9 |

주요 동선은 다음과 같습니다.

1. 신규 팀: 로그인 → 내 팀 목록 → 팀 생성 → 팀 홈 → 멤버 초대.
2. 초대 참여: 이메일 링크 → 초대 확인 → 필요 시 로그인 → 초대 수락 → 팀 홈.
3. 일정 조율: 내 일정 저장 → 팀 홈 → 조건 설정 → 추천 후보와 회차별 참석자 확인 → 확정 → 일정 상세.
4. 연습 기록: 팀 홈 → 일정 상세 → 영상 추가 → 영상 상세 → 피드백 작성.

추천 결과에서 조건으로 돌아가면 입력값을 유지합니다. 영상 상세에서 뒤로 가면 원래 일정 상세로 돌아갑니다. 로그인 전 열었던 초대나 접근 가능한 상세 화면은 로그인 후 복원합니다.

## 3 공통 화면 규칙

### 기본 배치

- 비로그인 화면: 서비스 이름, 화면 제목, 핵심 행동 버튼을 가운데 배치합니다.
- 로그인 화면: 상단에 팀 전환과 사용자 메뉴, 왼쪽에 팀 일정·내 일정·팀 멤버 메뉴, 본문에 화면 제목과 주요 행동을 배치합니다.
- 팀을 선택하지 않은 상태에서는 내 팀 목록과 내 일정만 접근합니다.
- 일정 상세와 영상 상세에는 상위 화면으로 돌아가는 경로를 표시합니다.
- 좁은 화면에서는 메뉴를 접고, 추천 비교표를 후보별 카드로 바꿉니다. 회차 정보는 펼쳐 확인할 수 있게 합니다.

### 공통 상태와 피드백

| 상태 | 화면 동작 |
|---|---|
| 최초 로딩 | 목록·본문의 자리 표시와 로딩 상태 표시 |
| 저장 중 | 해당 제출 버튼 비활성화, 처리 중 표시, 중복 제출 방지 |
| 저장 성공 | 성공 안내와 갱신된 데이터 표시. 필요 시 다음 화면으로 이동 |
| 저장 실패 | 입력을 유지하고 원인과 재시도 방법 표시 |
| 빈 상태 | 데이터가 없는 이유와 다음 행동 표시 |
| 로그인 만료 | 로그인 안내 후 원래 경로 복원. 복원 가능한 작성 내용 유지 |
| 권한 없음 | 접근 불가 안내와 내 팀 목록 이동. 비공개 데이터는 노출하지 않음 |
| 삭제되었거나 없는 항목 | 존재하지 않는 항목 안내와 상위 화면 이동 |
| 미저장 내용이 있는 이탈 | 계속 작성 또는 나가기 선택 |

입력 오류는 해당 필드 아래에 표시하고 첫 오류 필드로 초점을 옮깁니다. 상태를 색상만으로 전달하지 않습니다. 모달은 제목과 닫기 버튼을 제공하고 키보드 초점을 내부에 유지하며, 종료 후 원래 버튼으로 복원합니다.

### 날짜와 참석 가능 여부

- 임시 기준 시간대는 `Asia/Seoul`이며, 조건 입력과 추천 결과에 표시합니다. 다중 시간대 지원은 별도 결정 사항입니다.
- 개인 일정은 시작 포함·종료 미포함으로 비교하는 방안을 제안합니다. 예: 19시 종료 일정은 19시 시작 연습과 충돌하지 않습니다.
- 개인 일정 미등록이나 동기화 실패를 곧바로 참석 가능으로 표시하지 않습니다. `일정 확인 필요` 상태를 별도로 둡니다.
- 개인 일정 입력을 마친 사용자가 `입력 완료`를 표시하는 방안을 제안합니다. 이후 수정하면 완료 표시를 다시 확인하며, 추천 결과에는 최신 확인 시각을 표시합니다.
- 추천의 참석 가능 여부는 일정 충돌 판단 결과입니다. 실제 참석 응답을 받는 기능은 이번 초안에 포함하지 않습니다.

## 4 역할과 권한 제안

PPT의 초대 권한과 역할 분담은 미정입니다. 아래는 초기 구현을 위한 제안이며, 권한 제한은 화면과 서버 모두에서 적용해야 합니다.

| 행동 | 관리자 | 일반 멤버 |
|---|---|---|
| 팀 일정·영상·피드백 열람 | 가능 | 가능 |
| 본인 개인 일정 관리 | 가능 | 가능 |
| 다른 사람의 개인 일정 제목·내용 열람 | 불가 | 불가 |
| 팀원 초대 | 가능 | 불가 |
| 조율 조건 입력·추천 조회 | 가능 | 가능 |
| 추천 결과를 팀 일정으로 확정 | 가능 | 불가 |
| 일정에 영상 추가·피드백 작성 | 가능 | 가능 |
| 본인이 등록한 영상·피드백 수정·삭제 | 가능 | 가능 |
| 타인이 등록한 영상·피드백 수정·삭제 | 불가 | 불가 |

멤버 강제 탈퇴, 관리자 양도, 팀 삭제, 정기 일정 수정·취소의 범위는 별도 결정 전까지 버튼을 제공하지 않습니다.

## 5 화면별 상세 명세

### AUTH-01 로그인과 회원가입

**목적:** 소셜 계정으로 가입하거나 로그인합니다. PPT 4~5에 근거합니다.

| 영역 | 표시·동작 |
|---|---|
| 서비스 소개 | 서비스명과 일정 조율·연습 영상 피드백에 대한 짧은 설명 |
| 소셜 로그인 | 채택한 제공자의 로그인 버튼. 제공자는 미정이므로 특정 서비스로 확정하지 않음 |
| 진행 상태 | 인증창 이동·응답 대기 중 중복 요청 방지 |
| 가입 결과 | 신규 사용자는 가입 처리 후, 기존 사용자는 로그인 후 원래 목적지로 이동 |

- 초대 링크로 시작했다면 로그인 후 INV-01로 복귀하며, 가입만으로 초대를 자동 수락하지 않습니다.
- 인증 취소는 오류로 단정하지 않고 로그인 화면에 머뭅니다. 인증 실패는 재시도 버튼을 표시합니다.
- 소셜 가입과 구글 캘린더 연결은 별개 동의 흐름으로 분리합니다.

**완료 기준:** 신규·기존 사용자 모두 인증 후 올바른 화면으로 이동하며, 실패 시 재시도할 수 있습니다.

### INV-01 초대 확인과 수락

**목적:** 이메일로 받은 초대를 확인하고 해당 팀에 참여합니다. PPT 4에 근거합니다.

| 영역 | 표시·동작 |
|---|---|
| 초대 정보 | 유효한 초대에서 팀명, 초대 대상 이메일, 초대 상태 표시 |
| 비로그인 행동 | `로그인하고 참여하기` → AUTH-01 |
| 로그인 행동 | 로그인 계정 확인, `초대 수락` → 참여 처리 후 TEAM-02 |
| 이미 참여한 상태 | `이미 참여 중인 팀입니다`와 `팀으로 이동` |

- 초대 토큰 검증 후 정보를 표시합니다. 비로그인 대상 이메일은 일부 가립니다.
- 제안: 초대 대상과 검증된 계정 이메일이 일치할 때 수락합니다. 불일치 시 계정 전환을 안내하며, 소셜 계정이 이메일을 제공하지 않는 경우의 인증 방식은 결정 필요입니다.
- 만료·무효·회수된 링크는 수락 버튼을 숨기고 팀 관리자에게 새 초대를 요청하도록 안내합니다.
- 연속 클릭이나 이미 수락한 링크 재접속으로 팀 참여가 중복되지 않아야 합니다.

**완료 기준:** 유효한 초대만 참여로 이어지고, 이미 참여한 사용자는 팀으로 바로 이동할 수 있습니다.

### TEAM-01 내 팀 목록

**목적:** 참여 중인 팀으로 이동합니다. 화면 추가 제안입니다.

- 팀 카드에 팀명과 본인 역할을 표시하고 선택 시 TEAM-02로 이동합니다.
- 상단 `팀 만들기`는 TEAM-03으로 이동합니다.
- 팀이 없으면 `참여 중인 팀이 없습니다`와 팀 만들기 버튼, 이메일 초대 링크를 통한 참여 안내를 표시합니다.
- 목록 로딩 실패 시 재시도를 제공하며, 실패를 팀 0개 상태로 표시하지 않습니다.

**완료 기준:** 여러 팀 사이를 이동할 때 선택한 팀의 데이터만 표시됩니다.

### TEAM-02 팀 홈과 일정

**목적:** 예정된 연습과 지난 연습 기록에 접근합니다. PPT 5·7에 근거합니다.

| 영역 | 표시·동작 |
|---|---|
| 머리글 | 팀명, 본인 역할, `일정 조율` 버튼 |
| 일정 탐색 | 월 이동, 오늘 이동, 캘린더·목록 전환 |
| 일정 항목 | 제목, 날짜·시간, 참석 가능 멤버 요약, 영상 수 |
| 일정 선택 | SCH-03으로 이동 |
| 팀 준비 안내 | 멤버가 부족하거나 일정 확인이 필요하면 멤버·내 일정 화면으로 안내 |

- 개인의 비공개 일정은 팀 캘린더에 노출하지 않습니다.
- 일정이 없으면 `첫 연습 일정을 정해보세요`와 일정 조율 버튼을 표시합니다.
- 지난 일정도 조회할 수 있어 연습 영상을 다시 찾을 수 있습니다.
- 영상 수는 실제 해당 회차에 연결된 개수이며, 정기 일정 전체의 합계가 아닙니다.

**완료 기준:** 예정·지난 일정에서 각 회차의 상세와 기록으로 이동할 수 있습니다.

### TEAM-03 팀 생성

**목적:** 첫 팀을 만들고 초대 흐름을 시작합니다. PPT에 없는 제안 화면입니다.

| 입력 | 필수 여부 | 검증 제안 |
|---|---|---|
| 팀 이름 | 필수 | 앞뒤 공백 제거 후 1~50자 |
| 팀 설명 | 선택 | 최대 200자 |

- `만들기` 완료 시 생성자를 관리자로 등록하고 TEAM-02로 이동합니다.
- 성공 안내에서 팀원 초대 화면으로 이동할 수 있게 합니다.
- 팀 이름의 전역 중복 제한은 두지 않는 방안을 제안합니다. 실제 팀 식별은 고유 ID로 처리합니다.
- 실패 시 입력 유지, 취소 시 TEAM-01 복귀. 팀 생성 요청의 중복 처리 방지가 필요합니다.

**완료 기준:** 생성된 팀이 내 팀 목록에 나타나고 생성자가 관리자 권한으로 진입합니다.

### TEAM-04 팀 멤버와 초대

**목적:** 팀 멤버를 확인하고 이메일 초대를 보냅니다. PPT 4·7에 근거합니다.

| 영역 | 표시·동작 |
|---|---|
| 멤버 목록 | 이름, 역할, 본인 표시. 타인의 로그인 이메일은 기본 비공개 제안 |
| 초대 버튼 | 관리자에게 `이메일로 초대` 표시 |
| 초대 현황 | 관리자에게 대상 이메일과 대기·수락·만료 상태 표시 |
| 초대 입력 모달 | 이메일 1개 입력, 취소·발송 버튼 |

- 이메일은 필수이며 공백 정리와 형식을 검사합니다.
- 기존 멤버나 유효한 대기 초대가 있으면 중복 상태를 안내합니다. 만료 초대에는 재초대 동작을 제안합니다.
- 발송 중 버튼을 비활성화하고 실패 시 이메일을 유지합니다. 성공 문구는 `초대 메일 발송을 요청했습니다`로 처리하여 수신 완료로 오해하지 않게 합니다.
- 초대 유효기간과 재발송 제한은 결정 필요이며 설정된 정책을 모달과 현황에 반영합니다.

**완료 기준:** 권한 있는 사용자가 초대를 발송하고 이후 상태를 확인할 수 있습니다.

### CAL-01 내 일정

**목적:** 추천에 사용할 본인의 바쁜 시간을 관리합니다. PPT 5·7에 근거합니다.

| 영역 | 표시·동작 |
|---|---|
| 개인 캘린더 | 날짜 이동, 직접 입력 일정과 구글 일정을 출처로 구분 |
| 직접 입력 | `일정 추가` → 제목·시작·종료 입력 모달 |
| 구글 연결 | 미연결·연결 중·연결 완료·재연결 필요 상태 |
| 동기화 상태 | 마지막 성공 시각, 실패 안내, 재시도 버튼 |
| 입력 확인 | 제안: 일정 확인 범위와 `입력 완료` 상태 표시 |
| 공개 안내 | 팀원에게 제목과 내용 대신 참석 가능 여부가 공유됨을 안내 |

| 입력 | 검증·동작 제안 |
|---|---|
| 제목 | 선택, 공백이면 `개인 일정`. 다른 팀원에게 비공개 |
| 시작·종료 | 필수, 종료가 시작보다 늦어야 함. 날짜를 넘는 일정 허용 |
| 종일 | 선택 시 날짜 단위 입력으로 변경 |
| 직접 입력 일정 선택 | 상세 확인, 수정, 삭제. 삭제 전 확인 |
| 구글 일정 선택 | 읽기 전용 출처 안내. 앱 안에서 외부 원본 수정은 제공하지 않음 |

- 구글 연결 후 동기화 대상 캘린더를 선택하는 방안을 제안합니다. 연결 거부 시 직접 입력 기능을 계속 사용할 수 있습니다.
- 연결 성공과 동기화 완료를 구분합니다. 동기화 실패·오래된 데이터는 추천 화면에서도 확인 필요 상태로 전달합니다.
- 연결 해제는 확인 후 처리합니다. 제안: 가져온 일정은 추천 대상에서 제거하고 직접 입력 일정은 유지합니다.
- 연결 해제, 일정 삭제·수정 후 기존 추천은 재조회가 필요합니다. 확정된 팀 일정을 자동 삭제하지 않습니다.
- 반복 개인 일정 직접 입력, 동기화 주기·기간, 완료 확인 유효기간은 별도 결정 사항입니다.

**완료 기준:** 저장된 바쁜 시간이 추천에 반영되고, 연결 실패와 일정이 없는 상태가 구분됩니다.

### SCH-01 일정 조율 조건

**목적:** 모임 조건과 참석 조건을 지정합니다. PPT 6~8에 근거합니다.

| 입력 | 필수 | 초기 화면·검증 제안 |
|---|---|---|
| 일정 제목 | 예 | 1~100자. 예: 장면 리허설 |
| 반복 주기 | 예 | 초기 범위는 매주. 다른 주기는 결정 필요 |
| 모임 길이 | 예 | 양수인 시간·분. 허용 단위와 최대 길이는 결정 필요 |
| 탐색 기간 | 예 | 시작일·종료일, 종료일이 시작일 이상 |
| 탐색 요일·시간대 | 예 | 제안 항목. 최소 1개 요일, 모임 길이를 담을 수 있는 시간 범위 |
| 참석 조건 | 예 | `전원 참석` 또는 `필수 멤버 지정` |
| 필수 멤버 | 조건부 | 필수 멤버 방식이면 1명 이상 선택. 팀에서 나간 멤버 선택 불가 |

- PPT의 `주 1회 2시간, 향후 4주, 전원 참석`은 설명 예시이며 확정 기본값이 아닙니다. 예시 채우기 기능으로만 활용할 수 있습니다.
- 전원 참석이면 현재 팀 멤버 전체가 대상이고 별도의 필수 멤버 선택을 비활성화합니다.
- 필수 멤버 방식에서는 필수 멤버가 모든 회차에 가능해야 후보로 표시하고, 나머지 멤버의 가능 여부도 함께 표시하는 방안을 제안합니다.
- 일정 데이터가 확인되지 않은 멤버는 경고하고 CAL-01 또는 TEAM-04로 안내합니다. 미확인 필수 멤버가 있으면 확정 가능한 추천을 만들지 않습니다.
- `추천 시간 찾기` 클릭 시 검증 후 SCH-02로 이동합니다. 조회 실패 시 조건을 유지합니다.

**완료 기준:** 사용자가 입력한 모든 조건이 결과 화면 요약에 그대로 반영됩니다.

### SCH-02 추천 결과

**목적:** 정기 시간 후보와 각 회차의 참석 가능 멤버를 비교합니다. PPT 6~8에 근거하며 확정 동작은 제안입니다.

| 영역 | 표시·동작 |
|---|---|
| 조건 요약 | 탐색 기간, 주기, 길이, 요일·시간대, 참석 조건, 시간대 |
| 후보 목록 | 요일·시작·종료 시각, 전체 회차 수, 필수 조건 충족 여부 |
| 후보 상세 | 회차별 실제 날짜와 가능·불가·확인 필요 멤버의 이름 |
| 데이터 기준 | 추천 산출 시각, 오래되거나 확인되지 않은 일정 정보 안내 |
| 조건 수정 | SCH-01로 복귀, 기존 입력 유지 |
| 후보 선택 | 관리자에게 `이 시간으로 확정` 표시 |

- 전원 참석 조건은 탐색 기간의 모든 회차에서 모든 멤버가 가능해야 충족합니다.
- 조건 미충족 시간을 추천 후보와 섞지 않습니다. 필요하면 `제외된 시간`에서 사유를 확인하게 합니다.
- 제안 정렬: 비필수 멤버까지 전원 가능한 회차 수 내림차순 → 전체 회차 참석 가능 인원 합계 내림차순 → 첫 시작 시각 오름차순. 전원 참석 조건에서는 시간순으로 표시합니다.
- 결과가 없으면 `현재 조건을 만족하는 시간이 없습니다`와 기간·시간대·참석 조건 수정 동작을 제공합니다. 시스템이 조건을 임의 완화하지 않습니다.
- 데이터 부족은 결과 0개와 구분하여 `일정을 확인할 멤버가 있습니다`로 표시합니다.

**확정 모달 제안:** 제목, 반복 시간, 첫·마지막 날짜, 생성될 회차별 날짜, 회차 수를 표시합니다. 확정 시 멤버·개인 일정·권한을 다시 검사하고 변경이 있으면 새 추천 조회를 안내합니다. 성공 시 첫 회차 SCH-03으로 이동하고 전체 일정은 팀 캘린더에 반영합니다. 생성 실패 시 부분 생성 여부를 확인할 수 있어야 하며 중복 일정 생성을 방지합니다.

**완료 기준:** PPT 예시에서 수요일은 네 회차 전원 가능으로 추천되고, 2주차 하린이 불가능한 금요일은 전원 참석 후보에서 제외됩니다.

### SCH-03 일정 상세

**목적:** 한 회차의 정보와 연습 영상을 확인합니다. PPT 9에 근거합니다.

| 영역 | 표시·동작 |
|---|---|
| 일정 정보 | 제목, 날짜·시작·종료, 시간대, 정기 일정의 회차 표시 |
| 참석 정보 | 확정 시점의 가능·불가·확인 필요 멤버. 실제 출석 확정으로 표현하지 않음 |
| 변경 안내 | 제안: 이후 일정 정보가 달라지면 최신 정보와 차이를 안내하고 자동 재조정하지 않음 |
| 영상 목록 | 제목, 등록자, 등록일, 피드백 수. 썸네일 미지원 시 기본 이미지 |
| 영상 선택 | VID-01로 이동 |
| 영상 추가 | 모달에서 제목과 영상 주소 입력 |
| 회차 이동 | 같은 정기 일정의 이전·다음 회차로 이동 |

- 영상이 없으면 `이 일정에 등록된 연습 영상이 없습니다`와 추가 버튼을 표시합니다.
- 영상 추가 모달의 임시 필드: 제목 필수 1~100자, 영상 주소 필수. 허용 서비스와 링크 형식은 결정 필요입니다.
- 등록 시 실제 재생 지원 여부를 구분합니다. 주소 형식이 맞는 것만으로 재생 가능을 보장하지 않습니다.
- 영상이 일정에 추가되면 다른 회차에 자동 복제하지 않습니다.
- 현재 회차의 영상 목록과 다른 회차의 영상 목록이 섞이지 않아야 합니다.

**완료 기준:** 하나의 일정에 여러 영상을 등록하고 각각의 상세로 이동할 수 있습니다.

### VID-01 영상 상세와 피드백

**목적:** 선택한 영상을 보고 그 영상에 대한 피드백을 남깁니다. PPT 9에 근거합니다.

| 영역 | 표시·동작 |
|---|---|
| 상위 경로 | 팀·일정 제목, 일정 상세로 돌아가기 |
| 영상 정보 | 제목, 등록자, 등록일 |
| 재생 영역 | 지원되는 링크는 플레이어 제공. 지원하지 않는 임베드는 원본 열기 제공 |
| 피드백 목록 | 작성자, 본문, 작성 시각, 수정 여부. 작성순 표시 제안 |
| 작성 영역 | 텍스트 입력, `등록` 버튼 |
| 본인 항목 메뉴 | 영상 제목·주소 수정, 영상 삭제, 본인 피드백 수정·삭제 제안 |

- 피드백은 공백만 입력할 수 없고 최대 2,000자로 제한하는 방안을 제안합니다. 등록 실패 시 본문을 유지합니다.
- 등록 성공 시 새 항목을 표시하고 입력란을 비웁니다. 연속 클릭으로 중복 등록되지 않게 합니다.
- 피드백이 없으면 `첫 피드백을 남겨보세요`를 표시합니다.
- 영상 접근 제한·삭제·재생 실패 시 원인을 안내하고 원본 열기 또는 등록자에게 확인하도록 안내합니다. 기존 피드백은 계속 확인할 수 있습니다.
- 영상 주소 수정 시 기존 피드백의 대상이 바뀔 수 있으므로 경고합니다. 피드백이 있는 영상의 주소 변경 허용 여부는 결정 필요입니다.
- 삭제 확인 문구는 `영상과 연결된 피드백이 함께 삭제됩니다`를 제안합니다. 삭제·복구 정책 확정 전에는 구현 결정이 필요합니다. 외부 원본 영상은 삭제하지 않습니다.
- 피드백과 영상의 접근 권한은 해당 팀 멤버로 제한합니다. 링크 방식은 원본 서비스의 공개·접근 설정도 적용됨을 등록 화면에서 안내합니다.

**완료 기준:** 영상 A에 남긴 피드백이 영상 B에 표시되지 않고, 권한 없는 사용자가 상세 주소로 접근할 수 없습니다.

## 6 화면 간 데이터 연결

| 데이터 | 화면에서 필요한 정보 | 연결 규칙 |
|---|---|---|
| 사용자 | 이름, 인증 상태, 검증된 이메일 | 초대 수락과 본인 작성 항목 판별 |
| 팀·멤버 | 팀명, 멤버, 역할 | 모든 팀 화면에서 동일한 팀 기준 유지 |
| 초대 | 대상 이메일, 팀, 상태, 만료 시각 | 수락 시 해당 팀의 멤버로 연결 |
| 개인 일정 | 소유자, 시작·종료, 출처, 동기화 상태 | 추천 계산에 사용, 상세 내용은 본인만 표시 |
| 조율 조건 | 제목, 기간, 주기, 길이, 탐색 시간, 참석 조건 | 조건 수정과 결과 요약에 유지 |
| 추천 후보 | 반복 시간, 회차별 날짜·멤버별 가능 여부, 산출 시각 | 확정 전에 최신 데이터로 재검증 |
| 팀 일정 | 정기 일정 묶음, 개별 회차, 일시, 참석 가능 정보 | 영상은 정기 일정 묶음 대신 개별 회차에 연결 |
| 영상 | 연결 회차, 제목, 주소 또는 파일, 등록자 | 하나의 회차에 여러 영상 |
| 피드백 | 영상, 작성자, 본문, 작성·수정 시각 | 반드시 선택한 영상에만 연결 |
