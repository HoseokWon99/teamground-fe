# 모바일 달력 가독성 개선

## 변경

- `MonthView.tsx`, `MonthView.css`: 640px 이하에서는 날짜·일정 건수 버튼과 선택일 agenda를 표시한다. 320/390px에서 칸 안에 제목과 시간이 길게 줄바꿈되지 않는다.
- 첫 선택은 표시 월의 첫 일정 날짜이며 일정이 없으면 1일이다. 월 이동은 새 월의 기본 선택으로 전환하고, 오늘은 서울 기준 실제 날짜를 선택한다. 앞뒤 달의 보이는 날짜도 선택할 수 있다.
- Agenda는 시간 범위, 전체 제목, 직접 입력/Google 출처 또는 참석·영상 요약을 표시한다. 종료일이 다르면 연도를 포함한 종료 날짜를 표시한다. 각 일정은 기존 상세/수정 흐름으로 연결된다.
- 날짜 버튼은 전체 날짜·일정 수와 선택 상태를 읽고 Enter/Space로 동작한다. 선택일 제목 변경은 polite live 안내를 사용한다. 일정 접근성 이름에도 종료 시각·다른 종료 날짜를 포함한다.
- 선택일 키보드 초점은 어두운 배경 위 흰색 안쪽 테두리로 구분한다. 데스크톱은 기존 칸별 일정을 유지하며 CSS display:none으로 모바일/데스크톱 버튼의 중복 초점 노출을 막는다.
- 신규 의존성, 데이터/API 계약 변경 없음. 일정은 기존 동작과 같이 시작 날짜에 연결된다.

## 검증

- `pnpm typecheck`: 통과.
- `pnpm build --outDir /tmp/teamground-calendar-dist --emptyOutDir`: 통과. 공유 QA 빌드와 충돌하지 않도록 별도 산출물을 사용했다. Zod 주석 및 기존 큰 청크 경고는 이 작업 범위에서 변경하지 않았다.
- `pnpm exec playwright test --config /tmp/teamground-calendar-playwright.config.mjs`: Chromium/Firefox/WebKit에서 7개 시나리오씩 21개 통과. 임시 설정은 저장소 기본 브라우저·서울 시간대·한국어 로케일을 유지하고 testMatch를 `calendar.spec.ts`, preview 포트를 4175, outDir을 위 경로로 분리했다.
- 영구 회귀 테스트: `tests/e2e/calendar.spec.ts`. 기본 설정에서 `pnpm build` 후 `pnpm exec playwright test tests/e2e/calendar.spec.ts`로 재실행 가능하다.
- 검증 범위: 320/390px 개인·팀 두 사용처, 10월 모든 날짜의 접근 이름, Enter/Space 선택, 빈 날짜, 다음/이전 월, 서울 날짜 경계의 오늘, 시간·제목·출처·참석·영상 정보, 일정 수정/회차 이동, 1280px 데스크톱과 모바일 전환의 단일 접근 버튼, 동일 날짜 다중 일정·긴 제목·자정 넘는 종료일, 문서/agenda 가로 넘침.

## 검토와 후속

- 루트의 사전 UI 방향 승인 후 구현. 최종 diff 검토에서 선택일 초점 대비와 시간 범위 접근성 이름 지적을 반영했고 재검증했다.
- 독립 QA 담당이 실제 화면 캡처·axe·통합 검증을 수행하며 결과는 같은 폴더의 QA 보고서로 합친다.
- 이 변경의 미해결 기능 없음. 실제 서버 연동, 다른 날짜에 걸친 일정의 모든 날짜 칸 표시 등은 새로 구현하지 않았다.
