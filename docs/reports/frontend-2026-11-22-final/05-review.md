# 책임자 리뷰 · 모바일·로딩·접근성 마감

2026-11-22 · 루트 에이전트

## 설계 검토

모바일 달력은 7열 날짜 선택과 선택일 agenda를 분리하여 좁은 칸의 과도한 줄바꿈을 해소한다. 작은 화면에서 날짜/건수를 표시하고, 선택일의 시간 범위·제목·상세를 별도 영역에서 읽는다. 데스크톱의 기존 월별 일정을 유지하고 숨긴 표현이 중복 키보드 정지점으로 남지 않게 한다.

성능 개선은 이미 존재하는 route lazy와 eager service 의존성을 실제 측정한 뒤 진행한다. 단순 청크 분할에 따른 경고 제거를 다운로드 개선으로 혼동하지 않는다. 동기 저장 복원·손상 데이터 보존과 미저장 이탈 보호는 유지한다.

React best-practices 스킬의 조건부 로딩·효과 최소화·상태 도출·타입/접근성 기준을 현재 Vite SPA에 맞춰 적용한다. Next.js 전용 구조를 도입하지 않는다.

## 최종 리뷰

### 모바일 달력

`2fa6c8b` 코드 및 7개 시나리오 × 브라우저 3종 회귀를 검토했다. 선택일 초기값은 해당 월의 첫 일정 날짜 또는 1일이며 월 이동·오늘 버튼은 선택을 함께 갱신한다. 숨겨진 desktop/mobile 표현은 display:none으로 중복 탭 이동과 접근 이름을 방지한다. 리뷰 요청으로 선택 날짜의 흰색 내부 초점 테두리와 agenda의 종료 시각·종료 날짜를 접근 이름에도 반영했다. 독립 시각 검증 결과를 추가 확인한다.

### 초기 로딩과 실패 복구

- App의 작업공간과 데모 도구를 분리하고, 초기 로그인에서 서비스·추천 계산을 불러오지 않게 했다. 추천 계산은 실행 시 import하며 권한·버전 재검사는 실행 시점에 유지한다.
- persistence schema의 Zod mini 전환은 기존 검증 조건을 동등한 API로 바꾸며 동기 복원과 추가 참조 검증을 유지한다. unknown/optional/nullable 처리 및 날짜·숫자 경계 검증을 검토했다.
- 로컬 실행 환경의 NODE_ENV=development가 개발용 React를 빌드에 포함하는 점을 발견했다. production끼리 비교하고 build 스크립트에 production을 명시한다. 스크립트는 현재 macOS/Linux 환경 기준이다.
- 서비스 import 중 로그인 취소는 호출 전에 AbortSignal을 확인한다. import 실패 시 새로고침 복구를 제공하고, 로그인 딥링크와 기존 미저장 이탈 보호를 회귀로 검증한다.
- 첫 리뷰에서는 데모 도구 닫기 시 unmount로 busy 상태가 사라지고, lazy 오류가 상위 폼을 제거할 위험이 있었다. 첫 펼침 이후 mounted 상태를 유지하고 local error boundary를 두도록 수정 요청했다. 수정 diff와 실패 시 폼값·이탈 보호 유지 회귀를 확인했다.

### 접근성 검증 한계와 샘플

실제 Safari 원격 자동화와 macOS 보조 접근 권한의 차단 근거를 확인했다. 200% 브라우저 UI 확대와 VoiceOver 청취도 실제 수행 근거가 없어 완료로 처리하지 않는다. 환경 요구와 재검증 범위는 03 기록에 명시했다. 제품 결함을 발견해 방치한 상태와 도구/권한 부족으로 미실행한 상태를 구분한다.

샘플 영상 두 형식의 오디오 스트림이 0개이며 8초 추상 애니메이션인 점을 독립 QA가 확인했다. 샘플에만 무음·시각 설명을 표시하고 video의 aria-describedby로 연결하도록 요청하여 diff를 확인했다. 실제 사용자 영상 정책은 변경하지 않는다.

## 로컬·독립 검증 리뷰

- 단위 74개 통과. Zod classic/mini에 3,198개 변형 입력을 적용한 검증·정규화 결과도 일치했다.
- 전체 브라우저 회귀 최초 실행은 55/58 통과했다. 실패 3개는 기존 월 heading 부분 일치가 새 agenda heading에도 매칭된 strict locator 오류였다. root가 월 heading의 exact:true 보완을 승인했으며 해당 3개 재실행은 3/3 통과했다. 최종 전체 결과는 원격 CI에서 확인한다.
- 독립 QA는 final production에서 11화면 axe 위반 0, Chromium 5모달 axe·키보드·복귀, WebKit 모달 양방향 Tab, 3종 브라우저 핵심 흐름을 확인했다. 신규 calendar/deep link·샘플 설명·데모 chunk 실패 시 입력 보호도 확인했다. 소스 34개 검증 전후 hash 일치 근거는 04에 기록한다.
- root가 320/390/1440px 팀 화면을 직접 확인하여 모바일 시간·제목·상세의 가독성과 기존 desktop 유지를 승인했다. 선택 날짜의 내부 초점 표시도 확인했다.
- fullPage 캡처에 화면 위로 숨겨진 skip-link가 페이지 중간에 나타나는 현상은 실제 viewport와 DOM에서 재확인했다. top=-100·비초점 상태이며 root가 실제 viewport 캡처에서 링크가 노출되지 않음을 확인하여 제품 결함과 구분했다.
- production 초기 로그인 JS 합계 537,773 → 486,146 bytes, gzip 추정 합계 171,436 → 156,649 bytes. 개발 런타임이 포함된 이전 로컬 값 763KB는 공정 비교에서 제외했다.

코드·설계 리뷰 승인. 최종 문서를 포함한 정확한 HEAD 및 원격 체크 성공을 확인한 후 Ready로 전환한다. 자기 자신 커밋 SHA를 문서에 포함하는 순환을 피하기 위해 최종 승인 SHA·CI 링크·Ready 상태는 PR 본문에 기록한다. 실제 Safari·VoiceOver·native 200% 확대 미검증은 승인 범위의 명시적 한계다.
