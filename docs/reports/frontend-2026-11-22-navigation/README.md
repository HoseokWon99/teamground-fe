## 완료 기준

- 팀 생성·일정 조율·피드백 신규/수정 입력에서 링크, 팀 전환, 계정 전환, 브라우저 뒤로/앞으로 이동 시 미저장 입력 보호.
- 계속 작성 선택 시 URL·입력·기존 세션 유지. 폐기 선택 시 원래 목적지 이동. 기존 개별 확인과 중복하지 않음.
- 새로고침·탭 닫기는 미저장 상태에서 브라우저 기본 이탈 확인 요청. 브라우저 정책상 실제 표시 제한은 검증 보고서에 명시.
- 저장 실패 시 입력과 보호 유지, 저장 성공 시 정상 이동. 저장 중 입력·이동의 경쟁으로 내용이 사라지지 않게 처리.
- 발표 예시를 채운 상태도 저장 전 입력으로 취급. 이미 저장된 초안 복원은 불필요한 확인을 하지 않음.
- 로그아웃·데모 초기화는 상태 변경 전에 이탈 의사를 확인하고 취소하면 세션·데이터를 변경하지 않음.
- 기존 영상 모달 보호와 로그인 복귀·권한 가드·lazy 라우팅 유지. 390px 대표 흐름 확인.
