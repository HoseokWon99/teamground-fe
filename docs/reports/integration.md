| teams_auth | AUTH-01, INV-01, TEAM-01·03·04, 로그인 취소 | [teams-auth.md](teams-auth.md) |

각 에이전트의 보고서에는 변경 파일, 동작, 직접 수행한 검증, 제한사항을 기록했다. 병렬 작업 중 일시적인 누락 모듈 오류는 모두 통합 후 해결했다.

## 루트 변경 내용

- `package.json`, `pnpm-lock.yaml`, `tsconfig.json`, `vite.config.ts`, `index.html`, `.gitignore`: 앱 구성·의존성·명령.
- `src/main.tsx`, `src/app/App.tsx`: 11개 화면 라우팅, 로그인·팀 접근 가드, 오류 경계, 코드 분할, 공통 레이아웃·데모 도구.
- `src/components/common.tsx`, `src/components/ui/*`, `components.json`: 공통 상태, 버튼, Radix Dialog 기반 모달. 모달 닫힘 시 원래 버튼 초점 복원.
- `src/styles.css`: 한국어 팀 작업 공간, 녹색·크림색 디자인, 390px 대응.
- `src/lib/types.ts`, `src/lib/utils.ts`: 공유 데이터 계약과 표시 유틸리티.
- `src/features/videos/pages.tsx`: 회차 상세, 참석 가능 정보, 회차 이동, 영상 추가·수정·삭제, 댓글 등록·수정·삭제, 오류·재시도.
- `public/demo/*`: 직접 생성한 8초 추상 도형 영상, MP4 재생용 버전, 포스터.
- `README.md`: 실행 방법, 발표 순서, 범위와 보고서 안내.

영상은 개별 회차에, 댓글은 개별 영상에 연결한다. 외부 영상 링크는 http/https만 허용하며 직접 재생 가능한 영상 이외에는 원본 열기를 제공한다. 재생 불가 상태에서도 댓글은 유지한다.

## 최종 명령 검증

- `pnpm typecheck`: 성공.
- `pnpm test`: 2개 테스트 파일, **18개 테스트 통과**.
- `pnpm build`: 성공, `dist/` 생성.
- FFprobe: 로컬 샘플 960×540, 8초 확인. MP4는 H.264 baseline/yuv420p/faststart로 생성.
- 최종 검증 브라우저 탭의 수집된 error 로그: 없음.

테스트는 4주 반복 조건, 금요일 제외, 시작·종료 경계, 미확인·동기화 실패, 입력 제한, 권한·소속, 확정 전 변경, 중복 확정·수락, 실패 후 재시도, 연쇄 삭제, 로그인 취소 후 세션 보존을 포함한다.

빌드에 Zod 내부 주석 annotation 경고와 500kB 초과 초기 JS chunk 경고가 남아 있다. 빌드를 막지는 않는다. 화면 단위 lazy import를 적용했으며 추가 번들 최적화는 후속 범위다.

## 실제 브라우저 검증

Codex 브라우저에서 UI를 직접 조작했다.

1. 관리자 지우 로그인 → 파동 극단 진입.
2. 발표 예시 조건 입력 → 추천 1개, 매주 수요일 19~21시 확인.
3. 10/14, 10/21, 10/28, 11/04 네 회차 전원 가능 정보와 확정 모달 확인.
4. 확정 → 첫 회차 진입 → 로컬 데모 영상 추가.
5. 영상 상세 → 댓글 등록 → 새로고침 후 댓글 유지 확인.
6. 390px 모바일에서 팀 홈 → 회차 → 영상 이동, MP4 플레이어 0:03/0:08 프레임 확인, 댓글 추가 성공.
7. 서연 계정으로 초대 로그인 → 수락 → 5명 팀 목록과 일반 멤버의 초대 버튼 미노출 확인.
8. 개인 일정 등록 → 캘린더 반영 → 입력 완료 표시 확인.
9. 모달 저장·닫힘 뒤 `일정 추가` 버튼으로 초점 복원 확인.
10. 데모 초기화 → 관리자 로그인 → 4명·초기 일정 1개 상태로 복원, 1440px 팀 홈 확인.

첫 WebM 플레이어 검증 도중 브라우저 탭이 종료되어 새 탭에서 재검증했다. 호환성을 높이기 위해 데모 재생 경로에 MP4를 사용했고 이후 실제 프레임 재생을 확인했다. 발표용 영상은 실제 리허설 촬영본이 아닌 생성한 추상 도형 샘플이다.

최종 브라우저에는 기본 데이터로 복원한 관리자 팀 홈을 남겼다. 임시 반응형 뷰포트 설정은 해제했다.

## 범위와 제한

- 실제 서버 인증·메일 발송·Google API·파일 업로드는 없다. 화면에도 데모임을 표시한다.
- 서비스와 화면의 권한 검사는 시연용이다. 클라이언트 저장소 자체는 신뢰 가능한 보안 경계가 아니다.
- 외부 영상 서비스 임베드 확대는 제외했다. 로컬 데모와 직접 미디어 링크는 플레이어, 나머지는 원본 열기를 사용한다.
- 폼별 취소·모달 닫기와 일부 링크 이탈 확인은 구현했다. 모든 화면의 브라우저 뒤로가기까지 포괄하는 통합 미저장 변경 차단은 아직 없다.
- 실제 브라우저 검증은 위 동선에 한정한다. 모든 오류 조합, 모든 브라우저, 모든 화면의 키보드 순회를 완료했다고 주장하지 않는다.
- 배포하지 않았다. 현재 `pnpm dev` 로컬 서버를 실행 중이며 http://localhost:5173 에서 확인할 수 있다.
