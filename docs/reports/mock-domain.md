# 공유 mock 도메인 구현 보고서

## 완료 범위

- 지우·하린·민서·도윤·서연 계정, 파동·프레임 팀, 개인 일정, 회차·영상·댓글, 유효·만료·수락 초대 seed를 하나의 상태로 연결했습니다.
- Zustand persist에 저장 버전, 데이터 전체 구조 검증, 저장소 실패 시 메모리 유지와 안내 메시지를 제공했습니다.
- 인증·팀 생성·초대·개인 일정·구글 동기화 시뮬레이션·조율·추천·확정·영상·피드백 API를 구현했습니다. 도메인 변경은 서비스에서 권한을 검증합니다.
- 160ms 비동기 지연, 동시에 중복 제출된 동일 요청 합치기, 다음 요청 한 번 실패, 데모 초기화·데이터 부족·후보 없음·확정 전 변경 시나리오를 구현했습니다.
- 추천은 서울 현지 날짜 문자열과 UTC 날짜 산술을 사용해 브라우저 시간대에 영향받지 않습니다. 매주 모든 회차를 검사하고 시작 포함·종료 미포함으로 비교합니다. 입력 미완료·기간 밖·동기화 오류는 확인 필요로 처리합니다.
- 관리자·소속·작성자 검증, 추천 버전 재검증, 전체 회차 일괄 생성과 중복 확정 방지, 피드백 있는 영상 주소 변경 제한·영상 삭제 시 피드백 삭제를 구현했습니다.

## 변경 파일

- `src/mocks/seed.ts`: 공유 초기 데이터, `exampleDraft(teamId)`
- `src/mocks/service.ts`: 비동기 mock 서비스
- `src/stores/useAppStore.ts`: 영속화 상태와 저장소 오류 보호
- `src/stores/app-store.ts`: 공통 import 경로 export
- `src/lib/recommendation.ts`: 반복 후보 계산
- `src/lib/recommendation.test.ts`: 핵심 로직·권한 검증

## 실제 수행한 검증

- `pnpm test`: 17개 테스트 통과 (2026-10-11).
- `pnpm typecheck`: 전체 화면 통합 후 재실행 통과.
- `pnpm build`: 전체 화면 통합 후 재실행 통과. Zod 의존성 주석과 500kB 초과 청크에 대한 비차단 경고가 출력되었습니다.
- 기본 조건은 수요일 10/14·10/21·10/28·11/04 네 회차만 추천하고, 10/23 하린 충돌 때문에 금요일 후보를 제외합니다.
- 경계 접점, 확인 미완료·기간·동기화, 필수 멤버 전환, 확정 전 변경, 중복 확정, 일반 멤버 권한, 다른 팀 영상 접근, 초대 이메일·중복 수락, 실패 후 재시도, 영상·댓글 연결 삭제를 검사했습니다.

## 제한 및 통합 확인 사항

- 추가 점검에서 추천 길이를 30~240분·30분 단위로, 탐색 기간을 시작·종료일 포함 최대 56일로 검증하도록 맞췄습니다. 범위 밖 길이와 8주 경계를 테스트했습니다.
- 저장값이 없는 최초 실행에는 복원 오류 메시지를 표시하지 않도록 수정하고 테스트했습니다.
- 실제 인증·서버 보안·메일·구글 API를 구현하지 않았습니다. 전부 브라우저 내부 시뮬레이션입니다.
- 로컬 영상 파일 제작과 재생, 브라우저 전체 흐름, 모바일·키보드 검증은 다른 담당 영역입니다.
- 서비스 삭제·초기화 호출 전 확인 UI는 각 화면 담당자가 제공합니다.
- 저장소 안내는 `storageWarning` export로 제공하며, 레이아웃에서 사용자에게 표시해야 합니다.
- 시나리오 변경은 추천을 무효화하며 기존 확정 일정을 삭제하지 않습니다. 기본 seed 전체 복원은 `reset()`입니다.
