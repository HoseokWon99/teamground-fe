## 구현 내용

팀 홈은 월 이동·오늘 이동·목록 전환, 회차 상세 이동, 팀 멤버와 역할, 일정 준비 상태를 표시한다. 영상 수와 참석 가능 인원은 공유 데이터에서 계산한다. 다음 연습은 오늘 이후 첫 회차를 선택하고 과거 일정만 있으면 최근 연습 기록으로 표시한다. 팀 생성 직후에는 성공 안내와 팀원 초대 진입 버튼을 표시한다. 달력은 date-fns로 월 경계를 계산하며, 날짜 키는 현지 날짜 문자열을 사용한다.

개인 일정은 React Hook Form과 Zod로 입력을 검증하며 직접 입력 일정 추가·수정·삭제를 제공한다. 종일 일정의 표시 종료일은 포함 날짜이며, 저장할 때 다음 날 00:00 종료로 변환한다. Google 샘플 캘린더 선택·동기화·재시도·연결 해제, 개인 일정 확인 기간과 입력 완료를 제공한다. Google 이벤트는 읽기 전용이다. 삭제와 연결 해제에 확인을 제공하고 저장 실패 시 폼을 유지한다.

조율 화면은 기간·길이·탐색 요일과 시간대·전원 또는 필수 멤버 조건을 검증한다. 길이는 30~240분의 30분 단위이며, 탐색 기간은 양 끝 포함 최대 56일(8주)로 공통 서비스 검증과 일치한다. 발표 예시는 명시적으로 버튼을 눌러 채우며, 추천 전 서비스로 팀별 초안을 저장해 결과에서 돌아왔을 때 복원한다.

결과 화면은 전체 조건 요약, 후보별 회차와 멤버 참석 가능 상태, 데이터 부족과 후보 없음 구분, 관리자 전용 전체 회차 확정 모달을 제공한다. 공유 데이터 버전 변경 시 후보를 확정할 수 없으며 재조회를 제공한다. 실제 확정과 권한·버전 검증은 공통 mock 서비스를 호출한다.

## 실제 수행한 검증

- 기준 문서와 AGENTS.md 확인.
- `vercel:react-best-practices` 스킬 검토: 렌더 중 도메인 상태 변경 없음, 사용자 변경은 이벤트 핸들러로 실행, 파생 목록은 공유 상태에서 계산, 로딩/중복 제출 방지 확인.
- `pnpm typecheck`, `pnpm build` 최종 통합 실행 성공. Vite 빌드는 의존성 주석 및 큰 번들 경고를 출력했으며 오류 없이 완료했다. 초기 실행 시 다른 에이전트의 미완성 모듈로 발생했던 오류는 해소되었다.
- mock 도메인 담당자와 시간 형식 계약 확인 후 일정 저장 형식을 `YYYY-MM-DDTHH:mm`으로 통일.

## 통합 검증과 제한

- 실제 브라우저에서 핵심 추천→확정 동선과 390px 배치, 종일 일정 등록/수정은 통합 담당자의 최종 확인 대상이다.
- 일정 모달 닫기와 조율의 팀 화면 복귀 링크는 미저장 입력 확인을 제공한다. 브라우저 뒤로 가기와 다른 사이드바 메뉴로 이탈하는 모든 경로를 막는 전역 미저장 보호는 구현하지 않았다.
- 반복 개인 일정, 드래그 편집, 실제 OAuth는 계획 범위에 포함하지 않았다.
