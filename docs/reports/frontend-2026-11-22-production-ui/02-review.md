# 운영 배포 루트 리뷰

2026-11-22. 사용자가 완성된 UI의 운영 배포와 `app.jointeamground.com` 확인을 명시적으로 요청했다.

## 대상·배포 절차 검토

- 배포 대상은 UI PR #11이 머지된 main `3f3d1998792acfbd0145d8021f76c37bffab86b0`이다. 코드 리뷰와 이전 필수 CI 성공 기록에 더해 main CI `45002277577`의 성공을 확인했다.
- 기존 파이프라인의 `workflow_dispatch`는 preview 전용임을 확인했다. production은 성공한 main quality의 workflow_run만 허용하므로 해당 배포 run `45002456746`을 재실행했다.
- 환경 보호 규칙을 변경하지 않았다. 현재 사용자에게 승인 권한이 있고 자기 실행 승인이 허용된 `vercel-production`의 정상 승인 절차를 사용했다. 배포 요청 자체가 이번 운영 실행의 승인이다.
- `VERCEL_ACTIONS_ENABLED`는 실행 진입을 위해 잠시 true로 설정한 뒤 false로 복원했다. Vercel Git 자동 배포 차단 설정도 유지했다.
- 토큰은 기존 GitHub Secret으로 전달했다. 비밀값을 출력하거나 저장소/산출물에 넣지 않았다.
- 원본 체크아웃의 사용자 수정은 보존하고 별도 worktree에서 배포 기록을 작성했다. 운영 소스는 원격 main이며 로컬 미커밋 파일을 배포하지 않았다.

## 검증 범위와 근거

배포 담당자의 워크플로·빌드·도메인 결과와 독립 QA의 실제 브라우저 결과를 대조한다. 공개 화면의 표시 성공, 실제 API 연결, 로그인 이후 업무 흐름은 서로 다른 완료 조건이다. 이전 로컬 BE 테스트 통과를 운영 인증 검증으로 대신하지 않는다.

운영 테스트 계정의 인증 세션이 없는 상태에서 시작했다. 실사용자 계정·데이터를 만들거나 변경하지 않고, 실제 메일 발송 및 Google 동의는 수행하지 않는다. 미확인 항목은 독립 QA 보고서에 남긴다.

## 최종 판단

운영 배포 run `45002456746`의 success, source SHA 일치, CLI `Ready in 9s` 및 `Aliased https://app.jointeamground.com` 기록을 확인했다. Vercel API 메타데이터는 MCP 403 때문에 직접 조회하지 못했으므로 CLI 로그와 실제 도메인 결과를 근거로 삼는다.

독립 QA는 새 `index-DKOmfEtU.js` 및 실제 이메일 로그인 화면을 확인했다. 데스크톱 1440px·모바일 390px에서 공개 인증/정책 화면, 계정 보호 경로, 404 총 14건을 확인했고 가로 넘침·JavaScript 예외·네트워크 전송 실패는 없었다. 예약 `.invalid` 주소의 비존재 계정으로 로그인 1회 요청하여 CSRF 200→로그인 401과 오류 안내·입력 유지까지 실제 운영 API에서 확인했다. 브라우저에서 CSRF 쿠키 저장과 CORS credentials 동작도 확인했다.

루트는 운영 로그인 화면의 데스크톱·모바일 및 로그인 실패 모바일 캡처를 직접 확인했다. 기본 인증 화면, 동작 버튼, 안내 및 정책 링크의 배치와 오류 메시지 표시가 정상이다.

**판단: 완성 UI의 운영 배포 및 비로그인 화면·API 연결 검증은 완료했다. 모든 인증 후 기능의 운영 정상 동작을 확인한 것은 아니다.**

- 운영 인증 세션이 없어 실제 로그인 성공·팀/일정/영상/피드백 쓰기·계정 탈퇴는 실행하지 않았다.
- BE 담당자의 읽기 전용 확인상 이메일 인증 코드는 운영 main `9b65c8c9f258c082857e52ad0d0f8106f7c47897`/ECS revision 8에 배포돼 있다. 그러나 Task Definition과 기본 설정에 SMTP host/from이 없으며 해당 버전 `SmtpAuthMailer`는 미설정 시 `503 AUTH_MAIL_UNAVAILABLE`를 반환한다. 신규 가입·재설정 메일은 운영 준비 미완료다. 실제 메일 요청은 하지 않았다.
- Google 인증 시작의 리다이렉트와 callback은 확인했으나 사용자 동의·로그인 완료는 미확인이다.
- Vercel 런타임 로그·모니터링은 접근 권한 부족으로 미확인이다. 브라우저에 관측된 오류가 없다는 결과를 서버 전체 오류 0건으로 확장하지 않는다.

상세 실행 근거와 한계는 `01-deployment.md`, `03-verification.md`에 기록했다. 배포 소스 변경 없이 기록만 별도 PR로 보존한다.
